# Product Growth Analytics: Funnel, Retention & A/B Testing using SQL

## Business Context

A digital product team has launched a new onboarding experience to improve user activation and purchase conversion.

Users were randomly assigned into two groups:

- Control group: users saw the existing onboarding experience.
- Variant group: users saw the redesigned onboarding experience.

The goal of this analysis is to determine whether the new onboarding experience should be launched to all users.

## Main Business Question

Should the company launch the new onboarding experience?

## Analysis Plan

To answer this, I will analyze:

1. User acquisition volume
2. Funnel conversion from signup to purchase
3. Drop-off points in the user journey
4. Segment performance by device and traffic source
5. A/B test performance between control and variant
6. Retention guardrail metrics
7. Revenue impact
8. Statistical significance
9. Final launch recommendation
